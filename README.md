# 💰 Controle Financeiro em Python
 
Programa desenvolvido em Python para registrar valores e armazenar informações automaticamente em uma planilha Excel.
 
## Funcionalidades
 
- Cadastro de valores
- Registro de valores a pagar (contas)
- Criação automática da planilha
- Armazenamento dos dados em Excel
 
## Tecnologias
 
- Python
- OpenPyXL
